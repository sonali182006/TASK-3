Random Password Generator

A beginner-friendly Python project that generates strong and secure random passwords.
This program allows users to create passwords with letters, numbers, and special characters for better security.

Features

Generate random passwords instantly

User-defined password length

Includes:

Uppercase letters

Lowercase letters

Numbers

Special characters


Strong and secure password creation

Beginner-friendly Python project


Technologies Used

Python 3

random module

string module


How to Run

1. Clone the repository:



git clone https://github.com/yourusername/Random-Password-Generator.git

2. Open the project folder.


3. Run the program:



python main.py
